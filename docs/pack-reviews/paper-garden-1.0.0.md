# Paper garden 1.0.0 review

This is the project's existing three-paper authoring example, submitted as the
first downloadable pack under the owner's instruction to establish publication.
The [published source](../../community/paper-garden/1.0.0) preserves the
[authoring example](../../puzzles/example-pack) byte for byte.

The pack credits Orifude contributors and declares Apache-2.0. Its puzzles were
created in this repository; there are no borrowed assets or additional license
terms. Each puzzle also declares Apache-2.0. The repository's Apache license
applies to this source. The ZIP contains declared TOML puzzle data and a plain-text note carrying the
full Apache license and attribution. The example includes the same note.

The progression moves from a single dot to one fold, then a short line. Titles,
descriptions, and tutorial cues describe those actions in plain text. Every
supplied solution passes the production engine, and the independent bounded
solver finds a solution to all three puzzles. Automated validation does not
prove uniqueness or replace a maintainer's judgment about puzzle quality.

The publication workflow requires the operator to attest to this review against
the exact source commit. Download, checksum, installation, and play verification
are recorded in the [working notebook](../../NOTEBOOK.md).
